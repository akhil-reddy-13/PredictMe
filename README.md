# Pattern or Noise?

Is this a real correlation — or random noise? Judge scatterplots one at a time; the debrief shows your false-positive rate and how you compare to a statistical tilt threshold.

## Stack

React + TypeScript + Vite + Tailwind. Pure TypeScript statistics in the browser.

## Commands

```bash
npm install
npm run dev
npm run build
npm run test
```

## Flow

1. **Intro** — hook  
2. **Primer** — how pattern vs noise is defined (plain language)  
3. **20 rounds** — pattern / noise  
4. **Results** — false-positive rate, ghosts gallery, error comparison, charts  
5. **Math** — optional detail
